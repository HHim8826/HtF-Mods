# HtF Radio Music（收音機自訂音樂）

[English](https://github.com/HHim8826/HtF-Mods/blob/main/mods/HtF.RadioMusic/README.md) | 繁體中文

把自己的音樂放進遊戲的收音機——可以一首歌一個頻率，像真的電台一樣自己接著播下去，
還可以讓整個房間聽同一首。

**只有你自己要裝。** 頻率是 `SyncVar` 會同步（別人看得到你在轉台），但音檔是本地的：
換成自訂音樂後只有你自己聽得到。**「同步播放」是這條規則的例外**，見下面。

## 音樂放哪裡

```
BepInEx/config/HtF.RadioMusic/
├── song.ogg          ← 直接放這裡的，依序輪流分配給各頻道
├── another.ogg
├── 1/                ← 放進來的指定給第 1 個頻道
│   └── ...
└── 2/                ← 第 2 個頻道，依此類推
```

資料夾和一份說明文字檔會在第一次執行時自動建好。

支援 `.ogg`、`.wav`、`.mp3`。**建議用 `.ogg`**——Unity 執行期解碼最穩。
`.mp3` 不一定所有環境都載得動，載不動會在 BepInEx log 留訊息。

按 **F8** 可以不重開遊戲就套用剛丟進去的檔案。

## 一首歌一個頻率

「頻道數」設 `0`（預設）就跟著曲目數走：每首歌一個頻率，上限是波段放得下的數量。

要在 88–108 之間塞下超過原版七台，得靠「頻道寬度」。原版一台在誤差 0.5 以內是滿音量、
超過 1.5 才完全消失，所以兩台要隔 3.0 才乾淨。把寬度調小，乾淨間距也跟著變窄，
台數再多都分得開；代價是調台越來越精細——真的 FM 收音機本來就是這樣。
設 `0` 會自動從頻道間距推一個寬度出來。

## 同步播放（一起聽）

打開「同步播放」，同一個房間的人會聽到同一首、同一個位置。

每個頻道的曲目串成一條連續的時間軸，像電台的節目表，由 FishNet 的網路時間決定現在播到哪裡。
純計算——**不送任何封包**。

兩個前提，而且 mod 沒辦法替你保證任何一個：

- 每個人都要裝這個 mod，而且
- 每個人的音樂資料夾內容要一模一樣。mod 沒辦法替你發音檔。

打開之後「下一首」會失效——跳過是本機動作，沒辦法讓其他人跟著跳。

## 安裝

**用 mod 管理器（建議）。** 從 Thunderstore Mod Manager 或 r2modman 安裝，按 Start modded。
BepInEx 會跟著一起裝。

**手動。** 先裝 [BepInEx 5.4.23.5](https://thunderstore.io/c/how-to-fish/p/BepInEx/BepInExPack/)，
再把 `HtF.RadioMusic.dll` 放進 `BepInEx/plugins/`。

## 設定

`BepInEx/config/htf.radiomusic.cfg`，第一次執行後產生。也可以在遊戲裡用
[HtF Config Menu](https://github.com/HHim8826/HtF-Mods/tree/main/mods/HtF.ConfigMenu)（F9）直接調。

| 分區 | 項目 | 預設 | |
|---|---|---|---|
| 聲音 | 雜訊音量倍率 | 1.0 | 沒調準時的沙沙聲。0 = 完全關掉。0 – 3 |
| | 音樂音量倍率 | 1.0 | 頻道音量。遊戲原本的基準是 0.3。0 – 5 |
| | Boss 出現時繼續播放 | 關 | 遊戲預設在 Boss 登場時把收音機整個靜音 |
| | 自動接下一首 | 開 | 一個頻道分到多首歌時自己接著播 |
| | 同步播放 | 關 | 見上面 |
| 頻道 | 頻道數 | 0（自動） | −1 = 用遊戲原本的頻道。0 = 一首歌一台。其他數字 = 指定幾台。−1 – 20 |
| | 頻道寬度 | 0（自動） | 1 = 遊戲原本的寬度。0 – 2 |
| 按鍵 | 下一首 | F7 | |
| | 重新載入音樂 | F8 | |

順帶一提，那個沙沙聲是遊戲刻意做的——它依「離最近頻道多遠」算出音量來模擬 FM。
「雜訊音量倍率」只是把它整體縮放。

### 什麼時候「下一首」會沒反應

「頻道數」是自動時，每個頻道本來就只有一首歌，沒有下一首可跳。要讓「下一首」和
「自動接下一首」有意義，頻道數得少於曲目數——設 `−1` 用遊戲原本的頻道最省事。

### 為什麼 .cfg 裡是中文

`.cfg` 裡的分區名與項目名不管切換到哪個語言都維持中文。它們是**識別字**不是顯示字：
BepInEx 靠它們找回你存的值，翻譯它們等於把每個調好的設定當成全新項目重生，
使用者的值會全部掉回預設。上表列的是遊戲內設定頁面顯示的名稱。

## 相容性

- 《How to Fish》1.0.9，Unity 6000.4.4f1（Mono）
- BepInEx 5.4.23.5，Harmony 2.9

patch 目標在啟動時會驗證一次，遊戲改版把它們搬走的話會在 BepInEx log 留一行警告，
不會默默失效。
