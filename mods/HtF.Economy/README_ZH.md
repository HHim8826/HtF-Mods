# HtF Economy（經濟與釣魚生態）

[English](https://github.com/HHim8826/HtF-Mods/blob/main/mods/HtF.Economy/README.md) | 繁體中文

重新調整錢和魚：賣價、花費、新存檔的起始金錢、抽魚權重、個別物種倍率、保底，
以及魚咬鉤要多久。

這兩半本來是兩個 mod。它們其實是同一條曲線的兩端——**魚就是錢的來源**——
只調一邊幾乎一定會得到失衡的結果。

## 誰要裝

**房主。** 這裡的每一件事都在伺服器端結算。

**想讓顯示的售價一致就全員都裝。** UI 上那個售價是各自客戶端算的。只有房主裝的話，
其他人拿到的錢仍然是調整後的，只是他的 UI 顯示未調整的原價。

**咬鉤時間與抽魚權重是嚴格意義的房主專屬**：唯一的讀取點只在伺服器端跑，
純客戶端調它不會有任何效果。

## 從 HtF.FishingEcology 升級

那個 mod 已經併進這一個。**它還裝著的話請移除。** 兩份同時載入會讓抽魚權重被 patch 兩次，
倍率變成疊乘，而且沒有任何錯誤訊息。偵測到舊插件時，這個 mod 會在 BepInEx log 留一則警告。

把 `BepInEx/plugins/HtF.FishingEcology` 整個資料夾刪掉，或在 mod 管理器裡解除安裝。

既有的 `htf.economy.cfg` 直接沿用——金錢那半刻意維持原本的分區名與項目名。

## 安裝

**用 mod 管理器（建議）。** 從 Thunderstore Mod Manager 或 r2modman 安裝，按 Start modded。
BepInEx 會跟著一起裝。

**手動。** 先裝 [BepInEx 5.4.23.5](https://thunderstore.io/c/how-to-fish/p/BepInEx/BepInExPack/)，
再把 `HtF.Economy.dll` 放進 `BepInEx/plugins/`。

## 設定

`BepInEx/config/htf.economy.cfg`，第一次執行後產生。也可以在遊戲裡用
[HtF Config Menu](https://github.com/HHim8826/HtF-Mods/tree/main/mods/HtF.ConfigMenu)（F9）直接調。

### 倍率

| 項目 | 預設 | |
|---|---|---|
| 賣價倍率 | 1.0 | 所有物品的售價（`Item.TotalWorth`）。小於 1 = 硬核，大於 1 = 輕鬆。同時影響賣箱、NPC 收購，以及 UI 上顯示的價格 |
| 花費倍率 | 1.0 | 購買時實際扣的錢——商店、魚餌、口袋、配件、升級、賭注。**商店 UI 顯示的仍是原價，「買不買得起」也用原價判斷**，只有實際扣款會乘上它（扣到 0 為止） |

### 存檔

| 項目 | 預設 | |
|---|---|---|
| 新存檔起始金錢 | −1 | −1 = 不改（遊戲給 0）。只影響之後新建的存檔 |

### 釣魚

| 項目 | 預設 | |
|---|---|---|
| 啟用釣魚生態 | 開 | 關掉就完全走遊戲原本的抽魚權重。不影響上面的倍率 |
| 稀有判定門檻 | 0.25 | 權重小於等於「該魚餌表中最大權重 × 此值」的算稀有 |
| 稀有魚倍率 | 1.0 | 大於 1 = 稀有魚更常出現 |
| 常見魚倍率 | 1.0 | 調低等於相對拉高稀有魚 |
| Boss 倍率 | 1.0 | Boss 類的權重。遊戲自己「場上只能有一隻 Boss」的規則不受影響 |
| 個別倍率 | *留空* | 逗號分隔的 `名稱=倍率`，名稱用去空格全小寫（跟 `/spawn` 一樣），例：`tuna=5, giantpiranha=0.2`。會覆蓋上面三個 |
| 連續幾次沒稀有就保底 | 0 | 0 = 關閉。連續 N 次抽到非稀有後，下一次只從稀有項目裡抽。計數全房共用 |
| 咬鉤時間倍率 | 1.0 | 小於 1 = 咬得更快。改的是 `BaitInfo` 資產，離開遊戲時還原 |

### 除錯

| 項目 | 預設 | |
|---|---|---|
| 記錄金錢異動 | 關 | 每次扣款寫進 BepInEx log |
| 記錄每次抽取 | 關 | 每次抽到什麼寫進 BepInEx log，調倍率時很有用 |

### 稀有度是怎麼判定的

遊戲沒有魚的稀有度欄位——`Rarity` 只用在外觀。所以稀有度是從權重本身推出來的：
在同一張魚餌表裡，越難抽到的就越稀有。「稀有判定門檻」比的就是這個。

### 為什麼 .cfg 裡是中文

`.cfg` 裡的分區名與項目名不管切換到哪個語言都維持中文。它們是**識別字**不是顯示字：
BepInEx 靠它們找回你存的值，翻譯它們等於把每個調好的設定當成全新項目重生，
使用者的值會全部掉回預設。上表列的是遊戲內設定頁面顯示的名稱。
